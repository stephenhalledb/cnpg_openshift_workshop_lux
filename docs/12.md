
# Restore backup

Restore backup done in the previous script.
The restore will create a new cluster called cluster-restore.
It recovers from the object store with the Barman Cloud Plugin
(externalClusters with plugin barman-cloud.cloudnative-pg.io; serverName is the
folder of the source cluster in the bucket).

The restore takes a few minutes. 23_check_restore.sh waits until the
restore cluster is up and running before it checks the data.

Check the cluster with this command:

```

kubectl get cluster

NAME               AGE   INSTANCES   READY   STATUS                     PRIMARY
cluster-restore    73s   1           1       Cluster in healthy state   cluster-restore-1

```

# Command

```

envsubst < ./yaml/restore-cluster.yaml | oc apply -n ${namespace} -f-

```
