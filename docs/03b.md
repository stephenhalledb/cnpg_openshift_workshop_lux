
# Install the Barman Cloud Plugin

Backups and WAL archiving of the clusters go through the Barman Cloud Plugin
(a CNPG-I plugin). The built-in `barmanObjectStore` method is deprecated.
Do not confuse it with the kubectl-cnp plugin of 01_install_plugin.sh.

The plugin needs cert-manager, and it must run in the namespace of the operator
(openshift-operators). The script checks both, and installs what is missing
only if plugin_operator_minio_managed_by_admin="no" in config.sh.
The release manifest is made for cnpg-system, so its namespace is replaced.

# Check

```

oc get crd certificates.cert-manager.io
oc get deploy barman-cloud -n openshift-operators

```

# Command

```

oc apply -f https://github.com/cert-manager/cert-manager/releases/download/${cert_manager_version}/cert-manager.yaml

curl -sL https://github.com/cloudnative-pg/plugin-barman-cloud/releases/download/${barman_cloud_plugin_version}/manifest.yaml \
  | sed 's/namespace: cnpg-system/namespace: openshift-operators/' | oc apply -f -

```

The manifest is adjusted for OpenShift and EDB:
- runAsUser/runAsGroup 10001 are removed (restricted-v2 SCC needs a UID of the namespace range)
- yaml/barman-plugin-edb-rbac.yaml: the plugin only has rights on the group
  postgresql.cnpg.io, the EDB operator uses postgresql.k8s.enterprisedb.io

```

envsubst < ./yaml/barman-plugin-edb-rbac.yaml | oc apply -f -

```

# How the cluster uses it

```

ObjectStore (yaml/objectstore.yaml): bucket, endpoint, credentials, retention
Cluster (yaml/cluster-sample.yaml):
  plugins:
  - name: barman-cloud.cloudnative-pg.io
    isWALArchiver: true
    parameters:
      barmanObjectName: <ObjectStore name>
Backup (yaml/backup.yaml): method: plugin

```
