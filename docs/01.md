
# Install CloudNativePG plugin

CloudNativePG provides a plugin for kubectl to manage a 
cluster in Kubernetes. 
The plugin also works with oc in an OpenShift environment.
This plugin communicate with the PostgreSQL cluster and Kubernetes.

The script first checks if the plugin is installed and prints the result.
It installs the plugin only if it is missing and 
plugin_operator_minio_managed_by_admin="no" in config.sh
(with "yes" the administrator installs it and the script only checks).

# Check

```

command -v kubectl-cnp && kubectl-cnp version

```

# Command

```

curl -sSfL \
  https://github.com/EnterpriseDB/kubectl-cnp/raw/main/install.sh | \
  sudo sh -s -- -b /usr/local/bin

```
