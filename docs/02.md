
# Install operator

The operator can be installed like any other resource in Kubernetes, 
through a YAML manifest applied via kubectl.

The script first checks if the operator is installed and healthy and
prints the result. It installs the operator only if it is missing and 
plugin_operator_minio_managed_by_admin="no" in config.sh (with "yes" the
administrator installs it and the script only checks). After the install it waits
up to 2 minutes and prints the final status.

The operator image is private. Before the install the script checks the pull
secret postgresql-operator-pull-secret in openshift-operators and, if it is
missing, creates it with ./connect_edb_token.sh (user k8s, password
EDB_SUBSCRIPTION_TOKEN from .credentials.sh). Without it the pod stays in
ImagePullBackOff. An existing secret is kept: to replace it after a token change
run ./connect_edb_token.sh yourself (it also does a docker login if docker is
installed).

# Check

```

oc get subscription cloud-native-postgresql -n openshift-operators \
  -o jsonpath='{.status.installedCSV}'

oc get csv <installedCSV> -n openshift-operators \
  -o jsonpath='{.status.phase}'

```

The operator is installed when the phase is Succeeded.

# Supported Architectures

CloudNativePG Plugin is currently built for the following 
operating system and architectures:

- Linux
  - amd64
  - arm 5/6/7
  - arm64
  - s390x
  - ppc64le
- macOS
  - amd64
  - arm64
- Windows
  - 386
  - amd64
  - arm 5/6/7
  - arm64

# Command

```

oc apply -f ./yaml/operator-subscription.yaml

```

File ./yaml/operator-subscription.yaml:

```

apiVersion: operators.coreos.com/v1alpha1
kind: Subscription
metadata:
  name: cloud-native-postgresql
  namespace: openshift-operators
spec:
  channel: fast
  name: cloud-native-postgresql
  source: certified-operators
  sourceNamespace: openshift-marketplace

```
