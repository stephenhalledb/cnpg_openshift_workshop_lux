
# Backup PostgreSQL cluster

Backup a PostgreSQL cluster in S3 object storage.
The backup is done by the Barman Cloud Plugin (method: plugin) in the bucket
defined by the ObjectStore of the cluster (MinIO or AWS S3).

# Command

## backup.yaml file
```
apiVersion: postgresql.k8s.enterprisedb.io/v1
kind: Backup
metadata:
  name: cluster-sh-backup-test
spec:
  cluster:
    name: cluster-sh
  target: "primary"
  method: plugin
  pluginConfiguration:
    name: barman-cloud.cloudnative-pg.io
```

## Upgrade
```
oc apply \
    -f cluster-sample-upgrade.yaml
```
