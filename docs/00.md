
# Setup S3 storage

Backups and WALs are stored in an S3 object storage.
The script checks that the storage is available and prints the result.
The type is set by object_storage_type in config.sh: minio or aws.

# MinIO

- Checks the MinIO deployment in the namespace minio-system
- If it is missing and plugin_operator_minio_managed_by_admin="no" in config.sh,
  it is installed with minio/install_minio.sh
- Tests the S3 API: list the bucket, write and delete a test object
- Checks that s3_endpoint_url in config.sh points to this MinIO

```

oc get deployment minio -n minio-system

cd minio && ./install_minio.sh

aws --endpoint-url https://<minio-api-route> s3 ls s3://<bucket>/

```

# AWS

- Reads the credentials from the .aws.sh file
- Checks the credentials (aws sts get-caller-identity)
- Tests the bucket: list the bucket, write and delete a test object

```

aws sts get-caller-identity

aws s3 ls s3://<bucket>/

```

# Managed by the administrator

With plugin_operator_minio_managed_by_admin="yes" in config.sh MinIO is
not installed (the administrator installs it before this repo is used).
The check is still done and the result is printed.
99_delete_env.sh does not remove MinIO in this case.
